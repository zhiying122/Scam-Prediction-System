## 一、專案摘要

ScamOracle 是一套以「**以 AI 對抗 AI**」為核心理念的詐騙進化預測系統。面對台灣日益嚴峻的詐騙危機 — 83000 件年度案件、88.2 億元 的天文數字損失 — 現有防詐機制僅能在詐騙發生後被動回應。ScamOracle 從根本翻轉這個困局：我們不等詐騙發生，而是**在詐騙大規模爆發之前就預測到它**。

系統運用 Meta Llama 3（透過 Ollama 本地部署） 與 Google Gemini 等先進大型語言模型，逆向模擬詐騙犯的思維邏輯，從單一詐騙情境自動裂變生成數百種話術變種。接著透過 NLP 語意分析與 XAI 可解釋性技術，將每一句話術拆解為五個心理操控維度 — 我們稱之為「**Scam_DNA（詐騙 DNA）**」。最終，Isolation Forest 異常偵測演算法在 24 小時內識別新興詐騙手法的趨勢變化，實現真正的「預測式防禦」。

ScamOracle 不僅是一套技術系統，更是一個完整的問題解決方案：從**問題定義**（台灣詐騙現況與話術演化趨勢）、到**解決方法論**（NLP 語意分析、異常偵測、LLM 預測之整合方案）、再到**可量化的成效指標**（提前 24 小時預警、88.9% 偵測準確率、使用者防詐意識提升），形成一條完整的價值鏈。

**核心數據一覽：**

| 指標 | 數值 |
|------|------|
| 系統功能頁面 | 12 個互動式功能頁面 |
| API 端點 | 7 個標準化 REST API |
| 自動化測試 | 410 個（含單元測試、Property-Based Testing、整合測試） |
| 語意向量維度 | 384 維（Sentence-BERT） |
| 預警提前時間 | 24 小時 |
| XAI 偵測準確率 | 88.9% |

## 二、問題背景

### 2.1 台灣詐騙危機的嚴峻現實

台灣正面臨史上最嚴重的詐騙危機。根據內政部警政署 165 反詐騙諮詢專線的公開統計數據：

- **2023 年全台詐騙案件達 83000 件**，較前一年增長 28%
- **年度損失金額高達 88.2 億元**，較前一年增長 28%
- 投資詐騙平均每案損失 112 萬元，愛情詐騙平均每案損失 56 萬元
- 2024 上半年損失已達 62.1 億元，全年預估將再創新高

這些數字背後，是無數家庭的積蓄化為烏有、退休老人的養老金被騙光、年輕人的創業資金付諸東流。詐騙不僅是財務損失，更是對社會信任基礎的嚴重侵蝕。

### 2.2 詐騙話術的加速進化

更令人擔憂的是，詐騙手法正以前所未有的速度進化：

| 時期 | 主流手法 | 特徵 |
|------|---------|------|
| 2018 年以前 | 電話詐騙（猜猜我是誰） | 單一話術、容易識破 |
| 2019-2020 年 | 簡訊釣魚 + 假網站 | 開始利用數位管道 |
| 2021-2022 年 | LINE 假客服 + 投資群組 | 社群媒體滲透、長期養套殺 |
| 2023 年至今 | AI 深偽語音 + 虛擬貨幣 | AI 技術加持、跨國犯罪 |
| 未來趨勢 | AI 生成個人化話術 | 大規模自動化、難以辨識 |

詐騙手法每 6-12 個月就會進化一次，而且越來越精密。詐騙集團已經開始使用 AI 技術來生成更逼真的話術、克隆受害者親友的聲音、甚至製作深偽影片。**當詐騙犯開始用 AI 攻擊，我們的防禦也必須用 AI 來回應。**

### 2.3 現有防詐機制的根本困境

| 現有方案 | 運作模式 | 根本問題 |
|---------|---------|---------|
| 165 反詐騙專線 | 民眾被騙後打電話報案 | **純被動接報案**，無法預防 |
| 銀行交易監控 | 偵測異常交易後攔截 | **事後攔截**，錢已經轉出 |
| Whoscall 來電辨識 | 比對已知詐騙號碼資料庫 | **資料庫滯後**，新號碼無法辨識 |
| 政府宣導海報 | 提醒民眾注意詐騙 | **單向傳播**，缺乏互動與實戰訓練 |

所有現有方案的共同問題是「**被動防禦**」— 等到詐騙發生後才處理。等到新型詐騙手法被發現並加入資料庫時，已經有數千人受害。

**我們提出的核心問題是：能不能在新型詐騙大規模爆發之前就預測到它？**

## 三、解決方案

### 3.1 核心理念：以 AI 對抗 AI

ScamOracle 採用「**以 AI 對抗 AI**」的逆向思維 — 這是本專案最核心的創新點。

傳統防詐思維是「等詐騙出現 → 分析手法 → 建立防禦」，這永遠慢詐騙犯一步。ScamOracle 的思維是「**用 AI 模擬詐騙犯的思維 → 預測未來可能出現的詐騙手法 → 在詐騙爆發前就建立防禦**」。

這就像疫苗的原理：我們不是等人生病後才治療，而是先用減毒病毒讓免疫系統認識威脅，提前建立抗體。ScamOracle 就是台灣社會的「**防詐疫苗**」。

### 3.2 問題解決方法論

ScamOracle 的解決方案整合了三大技術支柱，形成完整的問題解決鏈：

**第一步：LLM 話術裂變生成（預測未來威脅）**

系統使用 Meta Llama 3（透過 Ollama 本地部署） 與 Google Gemini，從一個種子詐騙情境（例如「假冒銀行客服」）自動裂變生成數百種不同語氣、不同手法、不同切入角度的詐騙話術變種。這不是為了教人詐騙，而是為了「**在詐騙出現之前就預測它**」— 如果我們能預測詐騙犯下一步會怎麼說，我們就能提前防禦。

**第二步：NLP 語意分析 + XAI 可解釋性（理解威脅本質）**

生成的話術經過 Sentence-BERT（384 維語意向量）進行語意分析，TF-IDF 提取關鍵詞，K-Means 分群找出詐騙手法的「家族關係」。最關鍵的是 XAI 可解釋性分析 — 系統會高亮標記每句話中觸發心理操控的具體片段，讓人們真正「看懂」詐騙是怎麼運作的。

**第三步：異常偵測預警（提前發出警報）**

Isolation Forest 時間序列分析持續監控詐騙話術的趨勢變化。當系統偵測到某種新型詐騙手法的出現頻率異常上升時，會在 24 小時內發出預警，讓執法機關、金融機構、電信商能夠提前部署防禦措施。

### 3.3 系統處理流程

```
情境種子輸入 → LLM 話術裂變生成 → NLP 語意特徵萃取 → XAI 可解釋性高亮
    → Scam_DNA 五維心理特徵量化 → 異常偵測預警 → Risk Vector 風險向量輸出
    → API 串接金融機構即時防詐系統
```

整個流程由 FastAPI API Gateway 統一協調各模組之間的資料流轉，確保分析結果一致。
