

# ScamOracle — AI 詐騙進化預測系統

>
> **聲明：** 本專案未使用任何中國大陸開發之 AI 工具（如 DeepSeek、百度文心、通義千問等）

### 問題陳述文案

> **台灣正面臨史上最嚴重的詐騙危機**
>
> 投資詐騙平均每案損失 **112 萬元**，愛情詐騙平均每案損失 **56 萬元**。
> 現有防詐機制（165 專線、銀行監控、Whoscall）全部都是**被動防禦** — 等到新型詐騙被發現時，已有數千人受害。
>
> **核心問題：能不能在新型詐騙大規模爆發之前就預測到它？**

### 3.3 Scam_DNA 五維雷達圖視覺化設計

#### 視覺設計
- **圖表類型**：五維雷達圖（Radar Chart / Spider Chart）
- **尺寸**：佔解決方案區域的 40%，居中放置
- **五個軸**：信任建立、緊迫感製造、情緒勒索、權威偽裝、利益誘導
- **配色方案**：每個維度使用獨立顏色

#### 雷達圖軸線與配色

| 維度 | 顏色 | 色碼 | 圖示 | 說明 |
|------|------|------|------|------|
| 信任建立 | 綠色 | #4CAF50 | 🟢 | 詐騙犯建立虛假信任關係，讓受害者放下戒心 |
| 緊迫感製造 | 黃色 | #FFC107 | 🟡 | 製造時間壓力，迫使受害者在短時間內做出決定 |
| 情緒勒索 | 紅色 | #F44336 | 🔴 | 利用恐懼、愧疚等情緒操控受害者行為 |

| 利益誘導 | 紫色 | #9C27B0 | 🟣 | 以高報酬、免費贈品等利益吸引受害者上鉤 |

#### 雷達圖範例數據（三種詐騙類型對比）

```
                    信任建立
                         ╱╲
                        ╱  ╲
                       ╱    ╲
利益誘導 ──────────────── 緊迫感製造
                       ╲    ╱
                        ╲  ╱
                         ╲╱

━━━ 假冒檢警（權威偽裝 + 緊迫感突出）
┅┅┅ 投資詐騙（利益誘導 + 信任建立突出）
╌╌╌ 愛情詐騙（情緒勒索 + 信任建立突出）
```

#### 雷達圖說明文案

> **Scam_DNA — 詐騙話術的「基因定序」技術**
>
> 每一種詐騙手法都有它獨特的心理操控「基因」。ScamOracle 獨創 Scam_DNA 技術，
> 將每一段詐騙話術量化為五個心理操控維度：信任建立、緊迫感製造、情緒勒索、權威偽裝、利益誘導。
>
> 透過 paraphrase-multilingual-MiniLM-L12-v2 產生的 384 維語意向量分析，
> 系統能自動辨識詐騙話術的「家族關係」，追蹤它們的演化軌跡。
> 這是全台灣第一套將詐騙話術進行系統性基因定序的技術。

### 3.4 核心技術流程圖

```
情境種子輸入 → LLM 話術裂變生成 → NLP 語意特徵萃取 → XAI 可解釋性高亮
    → Scam_DNA 五維心理特徵量化 → 異常偵測預警 → Risk Vector 風險向量輸出
    → API 串接金融機構即時防詐系統
```
