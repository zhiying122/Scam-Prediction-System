## 啟動步驟

### 1. 啟動後端服務（Docker）

```bash
# 啟動 PostgreSQL、Redis、Qdrant
docker-compose up -d

# 確認服務狀態
docker-compose ps
```

### 2. 啟動 API Server（可選）

```bash
# 若需要展示 API 端點
uvicorn app.api_gateway.main:app --reload --port 8000
```

API 文件：http://localhost:8000/docs

### 3. 啟動 Streamlit 儀表板

```bash
streamlit run app/dashboard/streamlit_app.py
```

瀏覽器自動開啟：http://localhost:8501

## 頁面操作重點

### 🏠 系統總覽

- 展示系統架構圖與核心創新
- 強調「主動預測」vs「被動防禦」的差異
- 說明商業應用場景（B2B 金融、B2G 政府）

### 🤖 LLM 話術生成

**重點：這是最吸睛的 Demo，務必準備真實 API Key**

1. 在側邊欄輸入 OpenAI API Key（`sk-...`）
2. 輸入情境：「假冒銀行客服，聲稱帳戶異常」
3. 點擊「生成話術」，展示真實 GPT-4o 輸出
4. 勾選「同時執行 XAI 分析」，即時高亮顯示心理操控片段

**話術建議：**
- 「各位評審可以看到，系統在 3 秒內生成了 5 種不同語氣的變形話術，這就是我們的核心創新——不需要等受害者報案，AI 自己就能預測未來手法。」

### 🔍 XAI 話術分析

**重點：展示可解釋性，不是黑盒子**

1. 使用預設範例文字（已包含多種心理操控特徵）
2. 點擊「開始分析」
3. 指出高亮片段：「系統精準標記出『立即』、『24小時內凍結』這些緊迫感製造的關鍵詞」

**話術建議：**
- 「傳統系統只能說『這是詐騙』，但我們的 XAI 技術能告訴你『為什麼是詐騙』，具體是哪一段話術在操控你的情緒。」

### 📊 模型準確率評估

**重點：用數字說服評審**

1. 點擊「執行評估」
2. 展示混淆矩陣：TP（正確攔截）、TN（正確放行）、FP（誤判）、FN（漏判）
3. 指出關鍵數字：「召回率（攔截率）達到 87.5%，誤判率僅 12.5%」

**話術建議：**
- 「這不是空口說白話，我們用 16 筆測試資料驗證，攔截率達到 87.5%，遠高於傳統關鍵字過濾的 60-70%。」

### 🧪 沙盤推演

**重點：展示預測能力**

1. 選擇情境：「投資詐騙」+ 目標受眾「年輕族群」
2. 執行推演，展示預測的高風險特徵
3. 說明：「這些特徵是系統預測未來可能出現的，不是從歷史資料抄來的。」

### 🗺️ 受害風險地圖

**重點：視覺化呈現**

1. 展示不同年齡層 × 地區的風險指數矩陣
2. 指出最高風險區域
3. 說明：「政府可以根據這個地圖，針對高風險區域加強宣導。」

## 常見問題應對

### Q: 你們的資料從哪裡來？

A: 目前使用示範資料集（20 筆去識別化案例），未來可串接 165 反詐騙資料庫的公開資料。系統的核心創新在於「用少量種子資料，透過 LLM 擴增出大量變形」，不需要等幾萬人受害才能訓練模型。

### Q: 準確率 85% 怎麼算出來的？

A: 請看「模型準確率評估」頁面，我們用 16 筆測試資料（8 筆詐騙、8 筆正常）實際跑出混淆矩陣，召回率（攔截率）為 87.5%，精確率為 87.5%，F1 分數為 0.875。

### Q: 跟現有防詐 APP 有什麼不同？

A: 現有 APP 依賴「已發生的黑名單」，我們是「預測未來的變種」。舉例：詐騙集團今天換個網域、改個話術，傳統系統就失效了，但我們的 LLM 能預先生成這些變形，提前部署防禦。

### Q: 商業模式是什麼？

A: B2B API 授權給銀行（串接網銀匯款流程）、電商平台（掃描假賣場）、政府機構（165 反詐中心趨勢報告）。收費模式為 SaaS 訂閱制，依 API 呼叫次數計費。

### Q: 為什麼不用 DeepSeek？

A: 競賽規定禁用中國大陸開發的 AI 工具，我們使用 OpenAI GPT-4o 與 Google Gemini，完全符合規定。

## 海報重點

### 必須包含的元素

1. **標題**：AI 詐騙進化預測系統
2. **問題陳述**：傳統防詐永遠慢半拍（用圖表對比）
3. **系統架構圖**：LLM 生成 → NLP 分析 → XAI 高亮 → 預警輸出
4. **核心創新**：主動預測、低資料依賴、可解釋性
5. **效能數字**：攔截率 87.5%、誤判率 12.5%、預警時間 24 小時
6. **商業應用**：B2B 金融、B2G 政府（用 icon 呈現）
7. **技術棧**：GPT-4o、Sentence-BERT、FastAPI、Streamlit
8. **團隊分工**：Member A（後端/AI）、Member B（資料/前端）

### 視覺建議

- 使用紅色警示色系（符合防詐主題）
- 架構圖用流程圖呈現（Mermaid 或 draw.io）
- 混淆矩陣截圖放大顯示
- XAI 高亮截圖（彩色標記很吸睛）
