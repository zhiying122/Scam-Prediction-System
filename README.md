## 我們在解決什麼問題

台灣正面臨史上最嚴重的詐騙危機：

- 2023 年全台詐騙案件 **83,000 件**，年增 27%
- 年度損失金額 **88.2 億元**，年增 28%
- 2024 上半年損失已達 **62.1 億元**，持續攀升
- 投資詐騙平均每案損失 **85 萬元**，愛情詐騙 **42 萬元**
- 詐騙手法每 6-12 個月就會進化一次，從電話詐騙 → 簡訊釣魚 → LINE 假客服 → AI 深偽語音

現有防詐系統的根本問題是「被動防禦」— 165 反詐騙專線只能在民眾被騙後接報案，銀行只能在交易完成後攔截。等到新型詐騙手法被發現時，已經有數千人受害。

**我們的核心問題：能不能在新型詐騙大規模爆發之前就預測到它？**

---

## 我們如何解決

AEGIS CORE 採用「以 AI 對抗 AI」的逆向思維：

1. **LLM 話術裂變生成** — 用 Ollama（本地 LLM）逆向模擬詐騙犯的思維，從一個種子情境自動生成數百種詐騙變種話術。這不是為了教人詐騙，而是為了「在詐騙出現之前就預測它」

2. **NLP 語意分析** — 用 Sentence-BERT 將話術轉換為 384 維語意向量，用 TF-IDF 提取關鍵詞，用 K-Means 分群找出詐騙手法的「家族關係」

3. **XAI 可解釋性分析** — 不是黑盒子。系統會高亮標記每句話中觸發心理操控的具體片段，分為 5 種心理特徵：信任建立、緊迫感製造、情緒勒索、權威偽裝、利益誘導

4. **異常偵測預警** — 用 Isolation Forest 時間序列分析，在 24 小時內偵測新興詐騙手法的趨勢變化

5. **防詐免疫訓練** — 讓一般民眾透過互動式訓練，親身體驗詐騙話術，學會識破詐騙

6. **Risk Vector API** — 標準化的風險向量 API，可串接銀行、電信商、保險公司的即時防詐系統

## 環境需求與安裝

### 環境需求

| 項目 | 版本 |
|------|------|
| Python | 3.11 以上 |
| Ollama | 最新版（本地 LLM 服務） |
| 作業系統 | Windows / macOS / Linux |

### 步驟 1：安裝 Python 依賴

```bash
pip install -r requirements.txt
```

### 步驟 2：設定環境變數

```bash
cp .env.example .env
```

`.env` 中的關鍵設定：
```env
LLM_PROVIDER=ollama          # 使用本地 Ollama（免費、資料不外洩）
OLLAMA_MODEL=llama3.1:8b     # Ollama 模型名稱
```

### 步驟 3：安裝並啟動 Ollama

1. 從 https://ollama.com 下載安裝
2. 下載模型：`ollama pull llama3.1:8b`
3. Ollama 安裝後會自動在背景執行

## 啟動前端與後端

開兩個終端機：

**終端機 1 — 後端 API Gateway（port 8000）：**
```bash
python -m uvicorn app.api_gateway.main:app --reload --host 0.0.0.0 --port 8000
```

**終端機 2 — 前端 Dashboard（port 8501）：**
```bash
python -m streamlit run app/dashboard/streamlit_app.py
```

啟動後：
- Dashboard：http://localhost:8501（自動開瀏覽器）
- API 文件（Swagger UI）：http://localhost:8000/docs
- 健康檢查：http://localhost:8000/v1/health

## 12 個功能頁面詳細操作說明


### 1. 系統總覽

**不需要 LLM，不需要後端 API。**

### 2. 即時威脅監控

**功能：** SOC 風格的即時威脅監控中心，顯示當前威脅等級、預警事件串流、地區風險分布

**操作方式：**
1. 從側邊欄選擇「即時威脅監控」
2. 頂部顯示當前威脅等級橫幅（基於趨勢上升的詐騙類型數量判定）
3. 4 個即時統計指標：活躍威脅數、24h 新變種、今日案件、AI 詐騙佔比
4. 左側：預警事件串流（基於真實統計數據，確定性生成）
5. 右側：威脅分布長條圖 + 高風險地區 TOP 5
6. 點「刷新事件」可重新載入

**資料來源：** 基於 165 專線真實統計數據動態計算，不是隨機生成。

### 3. 詐騙對話模擬器

**功能：** 與 AI 扮演的詐騙犯進行即時對話，系統用 XAI 高亮標記每句話的心理操控手法

**操作方式：**
1. 從側邊欄選擇「詐騙對話模擬器」
2. 選擇詐騙情境：假冒銀行客服 / 投資詐騙 / 假冒政府機關
3. 點「開始模擬」
4. 在輸入框輸入你的回應，點「發送」
5. 觀察詐騙犯的回應 — 高亮標記的部分就是心理操控手法
6. 嘗試說「我要報警」「165」「不相信」來識破詐騙，識破分數會增加
7. 點「結束」查看結果和防詐提示

**需要：** Ollama 在跑 + 後端 API Gateway 在跑

---

### 4. 話術 DNA 圖譜

**功能：** 7 種詐騙類型的心理操控特徵分布矩陣與相似度分析

**操作方式：**
1. 從側邊欄選擇「話術 DNA 圖譜」
2. 查看 7×5 的心理操控特徵矩陣（數值越高越紅 = 越依賴該手法）
3. 查看話術相似度 TOP 5（哪些詐騙類型使用相似手法）
4. 查看危險等級排行（0-10 分）
5. 查看各類型核心話術關鍵詞

**5 個心理操控維度：** 信任建立、緊迫感製造、情緒勒索、權威偽裝、利益誘導

### 5. 話術進化時間軸

**功能：** 追蹤 2021-2026 年詐騙話術的演化歷程，7 種詐騙類型各有 6 年的進化資料

**操作方式：**
1. 從側邊欄選擇「話術進化時間軸」
2. 從下拉選單選擇詐騙類型（7 種可選）

4. 查看每年的時間軸卡片，注意「 最新手法」標記
5. 底部有 AI 預測的下一年趨勢（動態計算，永遠顯示明年）

**自動更新：** 如果當前年份超過 2026，系統會自動用 Ollama 生成當年度的時間軸資料，快取 30 天。

### 6. 詐騙免疫訓練

## 7 個 API 端點使用說明

```bash

```

### 查詢預警事件
```bash

```

### 查詢風險向量
```bash
curl -H "X-API-Key: test-key-001" http://localhost:8000/v1/risk-vectors
```

### XAI 高亮分析
```bash
curl -X POST http://localhost:8000/v1/analyze/highlight \
  -H "X-API-Key: test-key-001" \
  -H "Content-Type: application/json" \
  -d '{"text": "您好，我是銀行客服，您的帳戶異常，請立即提供驗證碼"}'
```

### 批次完整分析
```bash
curl -X POST http://localhost:8000/v1/analyze/batch \
  -H "X-API-Key: test-key-001" \
  -H "Content-Type: application/json" \
  -d '{"texts": ["您好，我是銀行客服", "恭喜中獎，請繳手續費"]}'
```

### 話術生成（需要 Ollama）
```bash
curl -X POST http://localhost:8000/v1/scam/generate \
  -H "X-API-Key: test-key-001" \
  -H "X-Operator-Id: admin-001" \
  -H "X-Operator-Role: 系統管理員" \
  -H "Content-Type: application/json" \
  -d '{"scenario": "假冒銀行客服", "target_audience": "中老年族群", "sample_count": 10}'
```

### 資料匯入（CSV/JSON）
```bash
curl -X POST http://localhost:8000/v1/data/import \
  -H "X-API-Key: test-key-001" \
  -F "file=@data/sample_scam_cases.csv"
```

## 技術棧

| 類別 | 技術 |
|------|------|
| 後端框架 | FastAPI + Uvicorn |
| LLM 整合 | LangChain + Ollama（主要）/ GPT-4o / Gemini（備用） |

| 前端 | Streamlit（12 頁面） |
| 測試 | pytest + Hypothesis (Property-Based Testing) |
| 容器化 | Docker + Docker Compose |
